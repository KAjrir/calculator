# Calculator

An on-screen calculator built with vanilla JavaScript as part of [The Odin Project](https://www.theodinproject.com/).

🔗 **Live demo:** https://kajrir.github.io/calculator/

## Features
- Addition, subtraction, multiplication and division
- Chained operations (evaluates one pair of numbers at a time)
- Keyboard support
- Handles edge cases such as division by zero

## Built with
HTML, CSS and JavaScript (DOM manipulation, event delegation)

## What I learned
- Managing UI state (first number, operator, second number) without a framework
- Handling both click and keyboard events with the same logic
